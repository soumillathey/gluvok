Scale Subsystem Error Codes & Diagnostics

UART_PORT_ERROR Hardware Fault

Cause: Failed to open serial port (/dev/ttyAMA0). Permissions or physical port busy.

Fix: Check user dialout group permissions and verify RS-232 converter connection to Hermes controller.
SCALE_TIMEOUT Protocol Sync

Cause: Serial buffer timeout (>300ms silence without complete indicator weight frame).

Fix: Verify scale indicator is set to continuous transmission mode and baud rate is configured to 1200 baud.
